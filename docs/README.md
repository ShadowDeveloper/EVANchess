# Documentation

EVAN is a local, evidence-linked chess analysis and commentary application. For an overview and quick start, see the [project README](../README.md).

- [Setup and configuration](SETUP.md): install prerequisites, configure Stockfish and an LLM provider, and run the app.
- [Development](DEVELOPMENT.md): repository layout, local frontend development, tests, linting, and type checking.
- [Architecture and evidence](ARCHITECTURE.md): analysis stages, claim provenance, storage, and limitations.
- [API reference](API.md): imports, analysis status, event streams, prioritization, and exports.
- [Historical documents](HISTORY.md): the original idea, research proposal, and implementation plan, preserved together. These documents describe past intentions and may not reflect the current code.

The current code and the non-historical documentation are the reference for implemented behavior. Review engine-supported claims and their scope rather than treating generated commentary as proof.
